Gamified BPMN Help Page

Use the LEFT MOUSE BUTTON to move Tasks and Gateways (Click and Drag)

Use the RIGHT MOUSE BUTTON to create connections between Tasks (Click and Drag)

Gateways evaluate TRUE or FALSE. RED connections equal to FALSe, GREEN connections = to TRUE

With no nodes selected, pressing the DELETE key removes the last connection made

Selecting a node, then pressing the DELETE key removes all connections to that node
