Gamified BPMN Help Page

BPMN Elements

Start Event is where the process starts

An Intermediary Event is an event that occurs between Start and End events

The End Event is where the entire process ends

Exclusive OR Gateway evaluates state of an incomming token, and breaks the flow into one (or more) mutually exclusive paths

Paralell Gateways break the flow into two concurrent tasks

Inclusive OR Gateways break the flow into one or more flows

Task/Activity is a single, atomic unit of work to be performed

Pools (Airport in this case) represent the whole process or system

Lanes represent a functional unit (such as Check-in, Security, etc) and contain logical groupings of tasks/gateways (flow objects)

Game Mechanics

- System attempts to verify the solution. Hints for tokens that did not make it from start to finish appear at the top of the diagram

- Move on to the next scenario

- Remove all connections between nodes

Use the LEFT MOUSE BUTTON to move Tasks and Gateways (Click and Drag)

Use the RIGHT MOUSE BUTTON to create connections between Tasks (Click and Drag)

Gateways evaluate TRUE or FALSE. RED connections = FALSE, GREEN connections = TRUE

With no nodes selected, pressing the DELETE key removes the last connection made

Selecting a node, then pressing the DELETE key removes all connections to that node
